Daybook — Calendar Connection Guide

Keep this with the tablet instructions. One-time setup.

You already have the Jane iCal link. Start here. No iPhone access or Apple password is needed. The link is read-only and updates itself.

1. Use the Jane link (recommended)

  1. Open Daybook → Sync (refresh icon at the top).
  2. Calendar source: ICS feed URL.
  3. Paste the Jane link she sent you. It looks like https://…janeapp.com/ical/…/appointments.ics.
  4. Leave the daily sync time at 03:30 unless you want another time.
  5. Tap Save calendar source, then Sync now.
  6. Scroll to Recent calendar events and check the results.

What you should see

  • Client titles like First L. (In-Person FNIHB/IRS/Bigstone) with the client name in a green badge.
  • Break - … rows labelled Break, Work, Personal, or Vacation.
  • Couples show both names; DBT shows all attendees and a Group badge.
  • The first sync imports recent history as completed. Today/future appointments show as To confirm.
The link is a password. Anyone who has it can read the calendar, including client initials and schedule. Do not paste it into messages, tickets, screenshots, or the shared bundle. Daybook stores it only in the local SQLite database on the NAS. If it is exposed, regenerate the feed in Jane and paste the new URL.

2. Reminders and follow-ups

  • After a session, confirm it on the desk screen or Overview: Done + notes in Jane or No-show.
  • Anything unconfirmed for 3 days appears under Needs attention; after 5 PM a banner appears until it is cleared. Change both in Settings.
  • Clients not seen for 60 days (configurable) and with nothing booked appear under Clients to review: mark Follow up or Discharged.
  • No email or external push service is used. The desk device is the reminder surface.

Optional: private iCloud access instead

Only if you want to stop using the Jane link. This requires her cooperation because Apple requires an app-specific password.

On her iPhone (read this to her)

  1. Open Settings → tap her name/photo.
  2. Tap Sign-In & Security (older iOS: Password & Security).
  3. Tap App-Specific Passwords → Generate Password.
  4. Name it Daybook → Create → use Face ID/passcode.
  5. Copy the four-group password and send it to you with the Apple ID email.
  6. Calendar app → Calendars at the bottom → note the exact name of the calendar Jane uses.

No “App-Specific Passwords”? Two-factor authentication is off or the Apple ID is managed by an employer; use the Jane link instead.

In Daybook

  1. Sync → iCloud CalDAV.
  2. Server: https://caldav.icloud.com.
  3. Apple ID + the app-specific password (not the main Apple password).
  4. Calendar name: the exact name, or leave blank.
  5. Save → Sync now → check Recent calendar events.

Troubleshooting

SymptomFix
Jane link sync failsOpen the link in a browser to confirm it still works. If Jane rotated it, paste the new link.
401/403 on CalDAVUse an app-specific password, not the Apple ID password.
“Calendar not found”Use the exact name from the error list, or leave the name blank.
Client names look wrongSync → Parsing rules → Test parse; the defaults match First L. (Service).
Times are shiftedSet the container TZ to America/Edmonton and check the tablet timezone.

Do not

  • Send or enter her main Apple ID password.
  • Post or screenshot the Jane link.
  • Create a new Apple ID or a new calendar.
