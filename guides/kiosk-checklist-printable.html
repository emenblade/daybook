Daybook — Android Kiosk Checklist

Aim: a tablet that boots into Daybook, cannot leave the page, stays awake, reconnects automatically, and shows the 5 PM reminder banner. See ANDROID-KIOSK-GUIDE.md for details.

1. Network

  • Tablet on Wi-Fi
  • WireGuard (or Tailscale) installed
  • Tunnel imported / signed in
  • Android → VPN → WireGuard → Always-on VPN + Block connections without VPN
  • Test URL loads: http://<NAS_WG_IP>:8484/login

2. Fully Kiosk Browser

  • Fully Kiosk Browser installed and opened once
  • Start URL: http://<NAS_WG_IP>:8484/kiosk?eink=1 (e-ink) or /kiosk (LCD)
  • JavaScript and cookies enabled
  • Landscape orientation
  • Logged in once with the PIN
  • Kiosk Mode / Lock enabled, settings PIN set
  • Start on Boot / Autostart enabled
  • Keep Screen On enabled
  • Restart App on Crash enabled
  • Reload on Reconnect / network error enabled
  • Status bar / navigation bar hidden if available
  • Website whitelist (PRO): only http://<NAS_WG_IP>:8484/*

3. Android settings

  • Fully set as Home app
  • Battery → Unrestricted for Fully
  • Screen lock → None (Fully has its own PIN)
  • Stay awake while charging
  • Screen timeout long / Never
  • Play Store auto-update off for Fully
  • Date & time automatic
  • Charger connected

4. Test before handing it over

  • Reboot → returns to Daybook by itself
  • Wi-Fi drop → reconnects and reloads
  • Home button → Daybook only
  • No way to reach Settings/other apps without PIN
  • Toggle No-show → Done + notes → undo
  • Overnight → still on the kiosk
  • After 5 PM with an outstanding session → banner appears
  • Clear the session → banner disappears
No email is involved. The tablet is the reminder surface. After the configured time (default 5 PM) a banner appears while sessions are unconfirmed. Adjust the 3-day threshold and time in Daybook → Settings.

If something breaks

  • Browser error: VPN down → reconnect WireGuard; Fully reloads.
  • PIN screen: log in again; cookie lasts 90 days. Don't clear cookies on exit.
  • Stale day: tap Refresh in e-ink mode / wait 5 minutes; check tablet clock.
  • App closes: battery optimisation still on; set Unrestricted.
  • Lost settings PIN: clear Fully's app data and reconfigure.
